# 🦎 모던 자바스크립트 Deep Dive

> 동작하는 코드를 넘어, **왜 그렇게 동작하는지** 설명할 수 있는 개발자가 되기 위한 스터디입니다.

> 프로그래밍 언어의 기본 개념과 동작을 정확히 이해하는 것이 중요합니다.
> 기본 개념과 동작 원리를 이해하지 못한 상태에서 복사해서 붙여넣기로 단순히 동작만 하는 코드를 만들고 거기에 만족한다면
> 여러분이 구현한 코드는 언제 무너져도 이상할 것이 없는 사상누각일 뿐입니다.
> 그리고 여러분의 문제 해결 능력은 어느 선에서 성장을 멈추고 말 것입니다.
>
> — 『모던 자바스크립트 Deep Dive』 4p

## 🔥 진행 방식

- `Git`**에 각자 학습한 내용을 정리해서 업데이트**
- **스터디 시간에 발표자를 랜덤으로 정하여 디스코드에서 발표 진행**
- **스터디 내용을 발표하고 서로의 의견을 나누는 시간을 가짐**
- JS, 면접 대비 질문들, 이력서 관련 대비가 가능하도록 진행
- ~~10월쯤 리액트에 들어갈 수 있도록 준비~~



### 일정
